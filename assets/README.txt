Put your own girl images here (transparent background recommended).

Walking (required to use images):
  walk.gif                      animated GIF, OR
  walk_1.png, walk_2.png, ...   PNG frames in order

Standing while asking you to drink (optional):
  talk.gif   or   talk.png   or   talk_1.png, talk_2.png, ...

If there is no talk image, the first walking frame is used while she waits.
If this folder has no images, the built-in drawing is used.
You can also point the setting waterReminder.imageFolder to another folder.
